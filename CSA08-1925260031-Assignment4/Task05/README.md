# Task 05 – Organising Python Modules and Packages

Run each approach from the Assignment4 root:

```bash
python Task05/approach_a_single_script.py
python Task05/approach_b_one_module/main.py
python Task05/approach_c_three_modules/main.py
python Task05/approach_d_package/main.py
```

Each version reads the same `input/sample.txt` and creates a main report plus a report for register numbers with at least three absent records. The sample is intentionally small, so the second report will contain only its header.
